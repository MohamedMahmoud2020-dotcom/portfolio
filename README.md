# Mohamed Mahmoud — Developer Portfolio

A responsive developer portfolio built with React, TypeScript and Vite. It includes selected case-study style project cards plus the full public GitHub repository archive for `MohamedMahmoud2020-dotcom`.

## Included

- Responsive landing page
- About / experience positioning
- Featured project cards
- Searchable archive of all public GitHub repositories
- Skills and technical capabilities
- GitHub and LinkedIn links
- Mobile navigation
- Accessible reduced-motion behavior

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

The project is ready for Vercel or Netlify. For Vercel, import the repository and keep the default Vite settings.
